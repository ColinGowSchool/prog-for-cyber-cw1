## Main program instructions

program will show the username and ip address

Then program will display keys, and values of the dictionary, then prompt the user to enter in a new key for the dictionary they'd like, then once they've done that they will be prompted to enter the value for the key they entered (measures took to prevent accidents, something must be entered to let it count so no blank entries, then the key must also not be within the current dictionary)

The program will display keys, and values of the dictionary, then the user will be prompted to enter a key from the dictionary to change, if the key is not within the dictionary the user will be prompted to try again, then once the key has been selected they must input the new key they'd like, no blank entries will be allowed

The program will display keys, and values of the dictionary, then the user will be prompted to delete any key from the dictionary, if the key is not within the dictionary then they will be prompted to try again

Then the program will show the current dictionary with it's keys and values, then show how many pairs are in the dictionary

At the end of the program the user will be prompted to run through the code again
