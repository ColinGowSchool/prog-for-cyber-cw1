## Main program instructions
This program will prompt you to enter your username, and password (username - "admin" password - "Testing321!"), to act more like an actual program what the user enters for the password will be hidden, if a failed attempt is detected then it will display information about it (ip address, the username, the event id, what event happened, and the timestamp that it happened at), if the correct details are entered, then the program will begin to end and will ask the user if they would like to go through the program again, otherwise if the wrong details are entered it will keep going until the right details are entered, or the user inputs an interrupt command
