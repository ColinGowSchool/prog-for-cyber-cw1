Enter password in (password123!) if not entered correctly within 3 tries, then the user will get locked out and will need to try again.

### option 1
Option 1 will start a security event counter, which prompts you to enter a password (correct password "blickingbots123") and it will count how many wrong, and correct you got, and if you entered more than 50% wrong, an alert will appear

### option 2
Option 2 will prompt you to enter a password (same password as last time), it will give you 10 attempts before shutting you out, if you do fail all 10 attempts, a message saying you need to try again later

### option 3
Option 3 will prompt you to enter a username, and password (username - "admin" password - "blickingbot123"), it will give you 3 attempts to enter the correct details, if neither of them are correct, then a message saying you reached the maximum amount of attempt will appear

### option 4
